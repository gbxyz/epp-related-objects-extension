# Extensible Provisioning Protocol (EPP) Extension for Related Objects

This document describes an extension to the Extensible Provisioning Protocol (EPP) that allows EPP clients to request the inclusion of related objects in responses to `<info>` commands.

This was originally submitted to the IETF as an [Internet-Draft](https://datatracker.ietf.org/doc/draft-regext-brown-epp-related-objects/), but was not adopted by the [regext](https://datatracker.ietf.org/wg/regext/) working group. Since IDs are not appropriate references for inclusion in the [EPP Extension Registry](https://www.iana.org/assignments/epp-extensions), this specification is now published at <https://gavinbrown.xyz/epp-related-objects-extension/>.
